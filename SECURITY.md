## Reporting a problem

Report a vulnerability privately through **Security → Report a vulnerability** on
this repository's GitHub page, not in a public issue. Useful reports name the
release or commit, what an attacker could do, and the steps to reproduce it.

Examples of what counts: a way for a crafted file, save or download to run code
through the installer, the launcher or the bridge; a way around the lab's save
isolation or its read-only view of the installed game; a credential or personal
data found in the repository, a release or its history.

## What never to post

Do not attach ROMs, ROM extracts, Dead Cells files, saves, save states, crash
dumps, generated asset packs, API keys, tokens or passwords to an issue, pull
request or report. Logs are welcome once paths and account names you consider
private are removed.

## Supported versions

Only the latest release and `main` receive fixes.
