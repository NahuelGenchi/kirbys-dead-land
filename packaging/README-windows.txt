Kirby's Dead Land

Start the launcher: double-click "Kirby's Dead Land" in this folder. Keep the
share folder beside it: it holds the mod's files. If Windows says it protected
your PC, choose "More info", then "Run anyway".

You need Windows on a 64-bit PC, Dead Cells from Steam, and your own Kirby Super
Star Ultra (USA) game file. The launcher checks each one and says what to do.
Guide: https://github.com/NahuelGenchi/kirbys-dead-land/blob/main/docs/LAUNCHER.md
