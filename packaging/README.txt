Kirby's Dead Land

Start the launcher: double-click kirbys-dead-land in this folder, or run
./kirbys-dead-land in a terminal. Keep the share folder beside it: it holds the
mod's files.

To add it to the applications menu, run ./add-to-menu.sh once (again after
moving this folder).

You need Linux on a 64-bit PC, Dead Cells from Steam, your own Kirby Super Star
Ultra (USA) game file, and the bubblewrap package. The launcher checks each one
and says what to do. Guide: https://github.com/NahuelGenchi/kirbys-dead-land/blob/main/docs/LAUNCHER.md

The launcher is free software under the GNU GPL version 3 (LICENSE). NOTICES.txt
and NOTICES-emulator.txt list the other software inside it and where to get the
source code.
