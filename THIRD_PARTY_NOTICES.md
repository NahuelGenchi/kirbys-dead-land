## Modified GPL source

The bridge builds melon-rs and melonDS with this project's patches, which are
part of this repository's source: `src/nds/melon-rs-gpu.patch` and the patch
stages in `tools/nds_*_patch.py`, applied by `tools/oracle_build.py` and
`tools/nds_build.py`. The bridge (`src/nds/lib.rs`) links that code, so the bridge
and anything distributed with it are covered by the GPL.

Source archives contain no binaries. Anyone who distributes a built bridge
(`libkssu_bridge.so`) must also offer its complete corresponding source: this
project's source at the same commit, plus melon-rs and melonDS at the revisions
above. The player packages ([releases](docs/RELEASE.md#player-packages)) ship the
bridge and the oracle runner, so each holds `LICENSE`, `launcher/NOTICES.txt` and
`packaging/NOTICES-emulator.txt` (as `NOTICES.txt` and `NOTICES-emulator.txt`),
which name the release tag as the source, and the release that carries them also
carries the source archive of the same commit. `scripts/build_bundle.py` refuses
programs that were built on a personal machine unless the bundle is marked as a
private test.
